Failure injection (demo)

Tell the invoice service to report itself unhealthy. The process keeps running — it just fails its health check, so the health node and this dashboard treat it as down. Watch the invoice card flip red within a refresh cycle, then restore it.

You can also take a service down for real from a terminal:
docker compose stop invoice-service — then docker compose start invoice-service to bring it back.
